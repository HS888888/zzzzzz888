OPC UA шлюз — как запустить

Краткая инструкция: запуск → настройка ПЛК → сохранить → старт

1. Запуск 2. ПЛК 3. Шлюз 4. Сохранить 5. Старт Тест Адреса

1 Запуск программы

Дважды щёлкните по одному из файлов в папке OPC_UA_Gateway:

  • run.bat — если установлен Python 3.11+
  • OPC_UA_Gateway.exe — если собран EXE (папка dist\)

Откроется окно со схемой: три зелёных блока ПЛК → жёлтый блок шлюза → блок клиента заказчика. Настройки меняются кликом по блоку на схеме.

Шлюз должен быть остановлен, чтобы менять настройки ПЛК и шлюза. Если запущен — сначала «Остановить».

2 Настройка ПЛК

Кликните на зелёный блок ПЛК на схеме. Заполните поля в диалоге и нажмите «Применить» (сохраняет в память, ещё не на диск).

NodeId Температураns=2;i=1001Откуда читать температуру на ПЛК. Взять из UaExpert, подключившись к ПЛК

3 Настройка шлюза

Кликните на жёлтый блок «Шлюз Windows» (gateway.py) на схеме:

Поле в окнеЧто вводитьЗачем
Порт 48414841Порт, на котором клиент заказчика подключается к шлюзу (UaExpert, SCADA)
URI пространства имёнНе менятьТехнический идентификатор OPC UA — обычно оставляют по умолчанию
Имя папки переменныхGatewayDataПапка в дереве OPC UA — здесь UaExpert найдёт все переменные
Интервал опроса2.0Как часто (сек) опрашивать все ПЛК
Интервал переподключения5.0Пауза (сек) перед повторным подключением, если связь с ПЛК оборвалась

Нажмите «Применить».

4 Сохранить настройки

Обязательно! На главном окне нажмите кнопку «Сохранить» на панели сверху. Без этого «Запустить шлюз» не сработает — настройки останутся только в памяти.

«Сохранить» записывает всё в файл settings.json рядом с программой.

5 Запустить шлюз

Нажмите «Запустить шлюз» на панели сверху.

  • Зелёные блоки ПЛК — контроллер доступен, данные читаются
  • Жёлтый шлюз — работает нормально
  • Красные блоки — нет связи: проверьте IP, порт 4840, NodeId, сеть

Клиент заказчика подключается к opc.tcp://<IP_этого_ПК>:4841, переменные — в папке GatewayData.

Кратко: встроенный тест

Кнопка «Тест / Эмулятор» на панели — проверка без реальных ПЛК. Программа сама поднимет три fake-контроллера на localhost, подставит тестовые адреса, сохранит настройки и запустит шлюз. Если всё OK — окно «Тест пройден», блоки на схеме зелёные. Для возврата к объекту снова укажите реальные IP в настройках ПЛК, сохраните и запустите.
