MS SERVICE — portable-версия
===========================

Запуск
------
- Дважды щёлкните Запуск.vbs или MS SERVICE.exe
- Окно терминала не нужно и не должно оставаться на экране
- Python устанавливать не нужно

Первый запуск
-------------
1. Настройте ПЛК и шлюз в окне программы (клик по блокам на схеме)
2. Нажмите «Сохранить» — рядом с exe появится settings.json
3. Нажмите «Запуск» для опроса ПЛК

Файлы рядом с программой
------------------------
- settings.json  — настройки (создаётся кнопкой «Сохранить»)
- logs\          — журнал на диске (gateway.log, ротация автоматически)

Папка _internal
---------------
Содержит библиотеки (DLL). Не удаляйте и не переименовывайте.

Сеть и firewall
---------------
- ПЛК: обычно порт 4840 (opc.tcp)
- Локальный шлюз для SCADA: порт 4841 (настраивается в программе)
- Разрешите входящие/исходящие для MS SERVICE.exe в брандмауэре Windows

Передача на другой ПК
---------------------
Скопируйте всю папку MS SERVICE целиком (exe + _internal + vbs).
