OPC UA Gateway — portable-версия (Astra Linux)
================================================

Запуск
------
- В терминале: ./Запуск.sh
- Или двойной щёлк по OPC_UA_Gateway (если файловый менеджер разрешает запуск)
- Python устанавливать не нужно

Первый запуск
-------------
1. Если скрипт не запускается: chmod +x Запуск.sh OPC_UA_Gateway
2. Настройте ПЛК и шлюз в окне программы (клик по блокам на схеме)
3. Нажмите «Сохранить» — рядом с программой появится settings.json
4. Нажмите «Запуск» для опроса ПЛК

Файлы рядом с программой
------------------------
- settings.json  — настройки (создаётся кнопкой «Сохранить»)
- logs/          — журнал на диске (gateway.log, ротация автоматически)

Папка _internal
---------------
Содержит библиотеки (.so, Qt, PySide6). Не удаляйте и не переименовывайте.

Системные библиотеки (Qt WebEngine)
------------------------------------
На целевой машине могут понадобиться пакеты из install_system_deps.sh
(обычно libnss3, libxkbcommon, libgl1 и др.). Сборка на Astra Linux
включает большую часть зависимостей в _internal, но WebEngine иногда
использует системные компоненты.

Сеть и firewall
---------------
- ПЛК: обычно порт 4840 (opc.tcp)
- Локальный шлюз для SCADA: порт 4841 (настраивается в программе)
- Разрешите порты в iptables/nftables или отключите блокировку для процесса

Передача на другой ПК
---------------------
Скопируйте всю папку OPC_UA_Gateway целиком (бинарник + _internal + Запуск.sh).
Если разработчик передал архив, сначала проверьте контрольную сумму:

  sha256sum -c opcua-gateway-astra-se18-x86_64.tar.gz.sha256

Затем распакуйте:

  tar xzf opcua-gateway-astra-se18-x86_64.tar.gz
